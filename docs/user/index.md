# Journals for Obsidian

The user manual for the Journals plugin. Every setting, code block and
migration path is documented here.

New here? Start with [Journals](/journals) to set up your first journal, then
[Views and blocks](/views-and-blocks) to put a calendar on screen.

Coming from another plugin? See [Coming from Periodic Notes](/guides/from-periodic-notes)
or [Coming from Calendar](/guides/from-calendar).
