# v3 Modals Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a typed, DI-wired modal service inside the v3 host module so feature code defines modals with typed props/result and opens them via `AsyncResult<TResult, ModalCancelled>`.

**Architecture:** A new sub-module under `src/infrastructure/host/modals/` exposes `defineModal()`, `useModal()`, `useModalService()`, and a `ModalService` class. The only file that imports `obsidian.Modal` is `internal/vue-modal-host.ts` — a `Modal` subclass that mounts a Vue app rooted at the user-supplied component, provides submit/cancel callbacks through Vue's inject API, and resolves the outer AsyncResult. DI module is composed into the existing `createHostModule(plugin)` factory.

**Tech Stack:** TypeScript strict mode, Vue 3 (SFC + `inject`/`provide`), Obsidian `Modal`, `@/infrastructure/di` (tokens, modules, `useService`, `inject()`), `@/infrastructure/result` (`AsyncResult`, `Result`, `Ok`, `Err`), `vitest`, `@testing-library/vue` + `@testing-library/user-event`, paraglide messages (`@/i18n/paraglide/messages`).

**Spec:** [`docs/superpowers/specs/2026-05-14-v3-modals-design.md`](../specs/2026-05-14-v3-modals-design.md)

## Conventions to follow (from project memory)

- **Field-initializer DI:** `readonly #x = inject(Token)` at declaration; do not assign in constructor body.
- **Eager bindings:** `c.register(Service).useClass(Service).eager()`; lifetime stays default (do not call `.lifetime(Lifetime.Container)`).
- **Errors:** every `Error` subclass in `errors.ts`; carry a `kind` discriminator string.
- **No spec-reference comments in source.** No `// (requirement N)` or "Satisfies …".
- **No WHAT-comments.** Only WHY-comments allowed. No narrative header JSDoc.
- **Tests:** colocate `*.test.ts` next to the implementation; one behavior per test; nested `describe()` blocks for hierarchy; `expectTypeOf` for type assertions; `@testing-library/vue` + `user-event` for component tests; black-box assertions on observable outcomes.
- **Result test helpers:** `import { expectOk, expectErr } from "@/infrastructure/result/testing"`.
- **No tests for the wiring, barrels, modules, or fakes.**
- **Trailing newline** on every file; prettier runs on commit via lint-staged.
- **Test commands (run after each task):** `npm test`, `npm run check:types`, `npm run check:lint`.
- **Commits:** conventional commit subject (`feat(host): …`, `test(host): …`, etc.). Never `--no-verify`. Never `Co-Authored-By:`.

```ts
const openModals: Modal[] = [];

export const __testing = {
  get openModals(): readonly Modal[] {
    return openModals;
  },
  lastOpenModal(): Modal {
    const last = openModals.at(-1);
    if (!last) throw new Error("__testing.lastOpenModal() called before any modal opened");
    return last;
  },
  reset(): void {
    for (const m of [...openModals]) m.close();
    openModals.length = 0;
  },
};

export class Modal {
  readonly app: App;
  readonly titleEl: HTMLElement;
  readonly modalEl: HTMLElement;
  readonly contentEl: HTMLElement;
  #opened = false;

  constructor(app: App) {
    this.app = app;
    this.modalEl = document.createElement("div");
    this.titleEl = document.createElement("div");
    this.contentEl = document.createElement("div");
    this.modalEl.append(this.titleEl, this.contentEl);
  }

  open(): void {
    if (this.#opened) return;
    this.#opened = true;
    openModals.push(this);
    document.body.append(this.modalEl);
    this.onOpen();
  }

  close(): void {
    if (!this.#opened) return;
    this.#opened = false;
    const index = openModals.indexOf(this);
    if (index >= 0) openModals.splice(index, 1);
    this.onClose();
    this.modalEl.remove();
  }

  onOpen(): void {
    /* override */
  }

  onClose(): void {
    /* override */
  }
}
```

This mock uses plain DOM (happy-dom provides `document`). The `__testing` registry lets modal-service tests simulate user-initiated dismissals (Esc / X / backdrop) by calling `__testing.lastOpenModal().close()`. The real Obsidian `Modal.open()` also fires `onOpen` after mounting; the close flow mirrors `onClose` then DOM removal. Production code in `vue-modal-host.ts` uses plain DOM APIs (`textContent`, `style.setProperty`, `classList.add`, `replaceChildren`) — no reliance on Obsidian's HTMLElement extensions.

- [ ] **Step 1: Create types.ts**

```ts
import type { Component } from "vue";

export interface ModalDefinitionInput<TProps, TResult> {
  component: Component;
  title: (props: TProps) => string;
  width?: number | ((props: TProps) => number);
  cssClass?: string | readonly string[];
}

export interface ModalDefinition<TProps, TResult> {
  readonly component: Component;
  readonly title: (props: TProps) => string;
  readonly width: ((props: TProps) => number) | undefined;
  readonly cssClass: readonly string[];
  readonly __result: (witness: never) => TResult;
}

export interface ModalApi<TResult> {
  submit: (value: TResult) => void;
  cancel: () => void;
}
```

`__result` is a phantom function that carries `TResult` so TypeScript can infer it from a `ModalDefinition` value (without it, `TResult` is unreferenced in the structural shape and inference falls back to `unknown` at `ModalService.open`). The function is never called at runtime — its parameter type is `never`, which has no inhabitants.

```ts
import type { ModalDefinition, ModalDefinitionInput } from "./types";

export function defineModal<TProps = void, TResult = void>(
  input: ModalDefinitionInput<TProps, TResult>,
): ModalDefinition<TProps, TResult> {
  const rawWidth = input.width;
  const width = rawWidth === undefined ? undefined : typeof rawWidth === "function" ? rawWidth : () => rawWidth;
  const rawCssClass = input.cssClass;
  const cssClass = rawCssClass === undefined ? [] : typeof rawCssClass === "string" ? [rawCssClass] : rawCssClass;
  return {
    component: input.component,
    title: input.title,
    width,
    cssClass,
    __result: (witness: never): TResult => witness,
  };
}
```

```ts
import { inject } from "vue";

import { ModalContextKey } from "./internal/modal-context";

import type { ModalApi } from "./types";

export function useModal<TResult = void>(): ModalApi<TResult> {
  const api = inject(ModalContextKey);
  if (!api) throw new Error("useModal() must be called inside a modal opened via ModalService.");
  return {
    submit: (value) => api.submit(value),
    cancel: () => api.cancel(),
  };
}
```

The thrown `Error` is intentional: `useModal()` outside a modal is a programmer error, not a runtime-recoverable condition. No new `Error` subclass needed. The returned object wraps the `ModalApi<unknown>` from injection in a `ModalApi<TResult>` shape — `submit`'s `TResult` parameter narrows `api.submit`'s `unknown`, avoiding a type cast.

## Task 8: Implement `VueModalHost`

**Files:**

- Create: `src/infrastructure/host/modals/internal/vue-modal-host.ts`

No direct test — exercised through `ModalService` in Task 9. This file is the only one in the modals module that imports `obsidian.Modal`.

The Vue side wraps the user's component in a tiny root component whose `setup()` runs `provideInjector(injector)` — that's the only way `provideInjector` works (it calls Vue's `provide()` which requires a `setup()` context). The root then renders the user's component with the typed props.

- [ ] **Step 1: Implement `VueModalHost`**

```ts
import { Modal } from "obsidian";
import { type App as VueApp, createApp, defineComponent, h } from "vue";

import { provideInjector } from "@/infrastructure/di";

import type { Injector } from "@/infrastructure/di";
import type { App } from "obsidian";

import { ModalContextKey } from "./modal-context";

import type { ModalApi, ModalDefinition } from "../types";

export type ModalOutcomeHandler<TResult> = (outcome: { kind: "submit"; value: TResult } | { kind: "cancel" }) => void;

export class VueModalHost<TProps, TResult> extends Modal {
  readonly #definition: ModalDefinition<TProps, TResult>;
  readonly #props: TProps;
  readonly #injector: Injector;
  readonly #onOutcome: ModalOutcomeHandler<TResult>;
  #vueApp: VueApp | undefined;
  #settled = false;

  onAfterClose: (() => void) | undefined;

  constructor(
    app: App,
    injector: Injector,
    definition: ModalDefinition<TProps, TResult>,
    props: TProps,
    onOutcome: ModalOutcomeHandler<TResult>,
  ) {
    super(app);
    this.#definition = definition;
    this.#props = props;
    this.#injector = injector;
    this.#onOutcome = onOutcome;
  }

  onOpen(): void {
    this.titleEl.textContent = this.#definition.title(this.#props);
    if (this.#definition.width !== undefined) {
      this.modalEl.style.setProperty("--dialog-width", `${this.#definition.width(this.#props)}px`);
    }
    for (const cssClass of this.#definition.cssClass) this.modalEl.classList.add(cssClass);

    const api: ModalApi<TResult> = {
      submit: (value) => this.#settle({ kind: "submit", value }),
      cancel: () => this.#settle({ kind: "cancel" }),
    };

    const injector = this.#injector;
    const userComponent = this.#definition.component;
    const userProps = this.#props as Record<string, unknown>;

    const root = defineComponent({
      setup() {
        provideInjector(injector);
        return () => h(userComponent, userProps);
      },
    });

    const app = createApp(root);
    app.provide(ModalContextKey, api as ModalApi<unknown>);
    this.#vueApp = app;
    app.mount(this.contentEl);
  }

  onClose(): void {
    this.#vueApp?.unmount();
    this.#vueApp = undefined;
    this.contentEl.replaceChildren();
    if (!this.#settled) this.#settle({ kind: "cancel" });
    this.onAfterClose?.();
  }

  dismiss(): void {
    this.close();
  }

  #settle(outcome: { kind: "submit"; value: TResult } | { kind: "cancel" }): void {
    if (this.#settled) return;
    this.#settled = true;
    this.#onOutcome(outcome);
    // Defer close so submit/cancel called inside setup() doesn't re-enter Vue's mount cycle.
    queueMicrotask(() => {
      if (this.#vueApp) this.close();
    });
  }
}
```

Notes on the design:

- `#settled` is set _before_ `this.close()` so `onClose`'s "settle as cancel" branch becomes a no-op.
- Obsidian's `Modal.close()` fires `onClose()`, which fires our `onAfterClose` callback so `ModalService` can drop the host from its open set.
- `dismiss()` is a thin alias for `close()` — used for plugin-teardown clarity.
- The constructor takes only the dependencies it uses: `app` (for `super(app)`), the DI `injector` (provided to the Vue root), the definition, props, and outcome handler. Plugin-level teardown is the `ModalService`'s job, not the host's.

- [ ] **Step 3: Implement `ModalService`**

```ts
import { inject, InjectorToken } from "@/infrastructure/di";
import { AsyncResult, Err, Ok, type Result } from "@/infrastructure/result";

import { ModalCancelled } from "../errors";
import { InternalObsidianAppToken, InternalPluginToken } from "../../internal/tokens";

import { VueModalHost } from "./vue-modal-host";

import type { ModalDefinition } from "../types";

export class ModalService {
  readonly #plugin = inject(InternalPluginToken);
  readonly #app = inject(InternalObsidianAppToken);
  readonly #injector = inject(InjectorToken);
  readonly #open = new Set<VueModalHost<unknown, unknown>>();

  constructor() {
    this.#plugin.register(() => {
      for (const host of [...this.#open]) host.dismiss();
    });
  }

  open<TProps, TResult>(def: ModalDefinition<TProps, TResult>, props: TProps): AsyncResult<TResult, ModalCancelled> {
    const { promise, resolve } = Promise.withResolvers<Result<TResult, ModalCancelled>>();
    const host = new VueModalHost<TProps, TResult>(this.#app, this.#injector, def, props, (outcome) => {
      resolve(outcome.kind === "submit" ? new Ok(outcome.value) : new Err(new ModalCancelled()));
    });
    this.#open.add(host as VueModalHost<unknown, unknown>);
    host.onAfterClose = () => this.#open.delete(host as VueModalHost<unknown, unknown>);
    host.open();
    // The inner promise resolves a Result; flatMap-identity flattens AsyncResult<Result<T,E>,…> into AsyncResult<T,E>.
    return AsyncResult.fromPromise(promise, () => new ModalCancelled()).flatMap((r) => r);
  }
}
```

The `flatMap` at the end flattens `AsyncResult<Result<T, E>, E>` into `AsyncResult<T, E>`. The inner promise never rejects (the executor's `resolve` is the only resolution path), so the `mapErr` argument to `fromPromise` is unreachable; it's still required by the API. We give it the same `ModalCancelled` for symmetry.

```ts
import { AsyncResult, Err, Ok, type Result } from "@/infrastructure/result";

import { ModalCancelled } from "./errors";

import type { ModalDefinition } from "./types";

export class FakeModalHandle<TProps, TResult> {
  readonly def: ModalDefinition<TProps, TResult>;
  readonly props: TProps;
  readonly resolvedTitle: string;
  readonly resolvedWidth: number | undefined;
  readonly resolvedCssClass: readonly string[];

  #settled = false;
  readonly #resolve: (r: Result<TResult, ModalCancelled>) => void;

  constructor(
    def: ModalDefinition<TProps, TResult>,
    props: TProps,
    resolve: (r: Result<TResult, ModalCancelled>) => void,
  ) {
    this.def = def;
    this.props = props;
    this.resolvedTitle = def.title(props);
    this.resolvedWidth = def.width?.(props);
    this.resolvedCssClass = def.cssClass;
    this.#resolve = resolve;
  }

  submit(value: TResult): void {
    if (this.#settled) return;
    this.#settled = true;
    this.#resolve(new Ok(value));
  }

  cancel(): void {
    if (this.#settled) return;
    this.#settled = true;
    this.#resolve(new Err(new ModalCancelled()));
  }

  get settled(): boolean {
    return this.#settled;
  }
}

export class FakeModalService {
  readonly #opens: FakeModalHandle<unknown, unknown>[] = [];

  get opens(): ReadonlyArray<FakeModalHandle<unknown, unknown>> {
    return this.#opens;
  }

  open<TProps, TResult>(def: ModalDefinition<TProps, TResult>, props: TProps): AsyncResult<TResult, ModalCancelled> {
    const { promise, resolve } = Promise.withResolvers<Result<TResult, ModalCancelled>>();
    const handle = new FakeModalHandle<TProps, TResult>(def, props, resolve);
    this.#opens.push(handle as FakeModalHandle<unknown, unknown>);
    return AsyncResult.fromPromise(promise, () => new ModalCancelled()).flatMap((r) => r);
  }

  lastOpen<TProps = unknown, TResult = unknown>(): FakeModalHandle<TProps, TResult> {
    const last = this.#opens.at(-1);
    if (!last) throw new Error("FakeModalService.lastOpen() called before any open()");
    return last as FakeModalHandle<TProps, TResult>;
  }

  dismissAll(): void {
    for (const handle of this.#opens) handle.cancel();
  }
}
```
