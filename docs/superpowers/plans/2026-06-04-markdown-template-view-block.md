# Markdown Template View Block Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `markdown-template` journal-view block that renders a referenced vault markdown file as formatted markdown, processing date-aware template variables against the view's focused date.

**Architecture:** A new view block (definition + render component + config component) reads a template file via `NotesService`, renders it with `TemplateEngine.renderString` using a date-centric `TemplateContext`, and paints the result through a new host `MarkdownRenderService` (wrapping Obsidian's `MarkdownRenderer`) surfaced by a reusable `UiMarkdown` component. The file is live-watched via `NotesService.events`. The generic file picker is promoted from journals to a shared `UiFileInput`.

**Tech Stack:** TypeScript, Vue 3 (`<script setup>`), valibot, custom DI (`@/infrastructure/di`), Obsidian API, vitest + @testing-library/vue + @testing-library/user-event.

import { Component, MarkdownRenderer } from "obsidian";

import { inject } from "@/infrastructure/di";

import type { Disposer } from "../input-suggests/types";

import { InternalObsidianAppToken } from "./tokens";

export class MarkdownRenderService {
  readonly #app = inject(InternalObsidianAppToken);

  render(element: HTMLElement, markdown: string, sourcePath: string): Disposer {
    const owner = new Component();
    owner.load();
    void MarkdownRenderer.render(this.#app, markdown, element, sourcePath, owner);
    return () => {
      owner.unload();
      element.replaceChildren();
    };
  }
}

import { onBeforeUnmount, onMounted, ref, watch } from "vue";

import { useService } from "@/infrastructure/di";

<script setup lang="ts">
import { computed, onBeforeUnmount, onMounted, ref, watch } from "vue";

import { CalendarDate, Clock } from "@/calendar";
import { useService } from "@/infrastructure/di";
import { NotesService } from "@/infrastructure/host";
import type { VaultPath } from "@/infrastructure/host";
import { m } from "@/i18n";
import { TemplateContext, TemplateEngine } from "@/templates";
import UiMarkdown from "@/ui/UiMarkdown.vue";

import { useViewContext } from "../../../view-context";

import type { BlockInstanceId } from "../../../config";
import type { MarkdownTemplateConfig } from "../markdown-template-block";

const props = defineProps<{ instanceId: BlockInstanceId; config: MarkdownTemplateConfig }>();

const notes = useService(NotesService);
const engine = useService(TemplateEngine);
const viewContext = useViewContext();

const rawTemplate = ref<string | null>(null);
const readFailed = ref(false);

const hasPath = computed(() => props.config.templatePath.length > 0);

async function load(): Promise<void> {
  if (!hasPath.value) {
    rawTemplate.value = null;
    readFailed.value = false;
    return;
  }
  await notes.read(props.config.templatePath as VaultPath).match({
    ok: (content) => {
      rawTemplate.value = content;
      readFailed.value = false;
    },
    err: () => {
      rawTemplate.value = null;
      readFailed.value = true;
    },
  });
}

const rendered = computed(() => {
  if (rawTemplate.value === null) return "";
  const focus = CalendarDate.fromAnchor(viewContext.refDate.value);
  const clockSpec = { kind: "clock", value: Clock.now(), defaultFormat: "HH:mm" } as const;
  const context = TemplateContext.empty()
    .date("date", focus, "YYYY-MM-DD")
    .date("current_date", CalendarDate.today(), "YYYY-MM-DD", { invertible: false })
    .withSpec("time", clockSpec)
    .withSpec("current_time", clockSpec);
  return engine.renderString(rawTemplate.value, context);
});

const unsubscribes: Array<() => void> = [];

onMounted(() => {
  void load();
  const reloadIfMatch = (path: string): void => {
    if (path === props.config.templatePath) void load();
  };
  unsubscribes.push(notes.events.on("metadata-changed", reloadIfMatch));
  unsubscribes.push(notes.events.on("created", (note) => reloadIfMatch(note.path)));
  unsubscribes.push(
    notes.events.on("renamed", (event) => {
      if (event.to === props.config.templatePath || event.from === props.config.templatePath) void load();
    }),
  );
});

watch(
  () => props.config.templatePath,
  () => void load(),
);

onBeforeUnmount(() => {
  for (const unsubscribe of unsubscribes) unsubscribe();
  unsubscribes.length = 0;
});
</script>

<template>
  <div class="journal-view-markdown-template">
    <div v-if="!hasPath" class="journal-view-markdown-template__empty">
      {{ m.view_block_markdown_template_empty() }}
    </div>
    <div v-else-if="readFailed" class="journal-view-markdown-template__error">
      {{ m.view_block_markdown_template_read_error() }}
    </div>
    <UiMarkdown v-else :markdown="rendered" :source-path="config.templatePath" />
  </div>
</template>

## Notes & deviations from the design doc

- **`cssClass` dropped from the block definition.** The view renderer (`src/views/view-leaf.ts`) renders blocks with `h(definition.component, …)` and does **not** apply a definition-level `cssClass`. The root-element class (`journal-view-markdown-template`) lives on the component template instead. Functionally equivalent; avoids implying behavior the view layer doesn't honor.
- **`UiMarkdown` tests cover render + re-render** (black-box). The unmount-dispose path is lifecycle plumbing exercised by the component itself; not separately asserted, per the project's no-trivial-tests convention.
- **`FakeNotesService.externalEdit`** was added to model an out-of-band vault edit (content change + `metadata-changed` emit). The real `NotesService` emits `metadata-changed` from `metadataCache.on("changed")`, which fires on content edits — so this is faithful, not error simulation.
