# Central Icon Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Introduce one central, typed icon map (`src/ui/icons.ts`) and migrate every authored icon string literal to reference it, unifying inconsistent glyphs by meaning.

**Architecture:** A single `as const` object grouped into `action` / `nav` / `entity` / `block` / `section`, with a derived `IconName` leaf-union type. Authored call sites (Vue `icon=`/`name=` props and `.ts` `icon:` definition fields) import `{ icons }` and reference keys positionally. User-entered icon inputs are left free-form.

**Tech Stack:** TypeScript, Vue 3 `<script setup>` SFCs, Obsidian Lucide icons, `@/` path alias (→ `src/`). Quality gates: `npm run check:types`, `npm run check:lint`, `npm test`, and the wdio e2e suite (this change is runtime-touching).

---

## Why no unit tests for the map

A constant object is exactly the trivial/wiring-test case this project excludes (no-trivial-tests, no-wiring-tests conventions). There is no behavior to test-drive. Correctness is enforced by `check:types` (every `icons.*` reference must resolve), existing component/e2e suites (they already render these icons), and a final grep proving no orphaned old literals remain. Do **not** add an `icons.test.ts`.

## Conventions for every migration step

- Add the import once per file: `import { icons } from "@/ui/icons";` (place it among the other `@/ui/...` imports, alphabetically if the file is sorted).
- A **static** Vue prop becomes a **bound** prop: `icon="pencil"` → `:icon="icons.action.edit"`; `name="hash"` → `:name="icons.section.numbering"`.
- A `.ts` definition field: `icon: "minus"` → `icon: icons.block.divider`.
- After each task, run `npm run check:types` and expect no new errors. Commit per task.
- Leave these three files' **user-entered icon inputs** untouched: `src/ui/UiIconSuggest.vue`, `src/commands/ui/EditCommandModal.vue`, and the `iconValue`/`UiIconSuggest` binding in `src/views/ui/ViewEditSubpage.vue` (lines ~40–45, ~92). ViewEditSubpage's _other_ icons (lines 87, 88, 122) ARE migrated.
